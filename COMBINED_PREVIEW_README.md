# Chestnut Combined Preview Package

This is a **rendered, buildable preview** combining the revised Chestnut website base with the industry-specific content additions from the earlier Claude project.

## Included and rendered
- Complete current site source and generated `dist/` static preview
- Four industry pages: Hotels & Hospitality, Contractors & Construction, Schools & Colleges, Airbnb & Short-Stay Accommodation
- `/insurance-by-industry/` hub linking to all four industry pages
- Advisory services, insurance/product pages, guides, and the current financial-product separation
- SEO titles/descriptions, canonical URLs, breadcrumbs and structured data where generated by the site build
- Build and QA scripts

## Local preview
Requires Node.js 18+.
1. Extract this package.
2. Run `npm test`.
3. Serve the generated `dist` folder with a local static server (for example `npx serve dist`).

## Important
This is a preview package only. It does not modify `chestnutpreview`, either GitHub repository, or any live website. The forms are not connected to an endpoint yet; this is shown by the build output. Six visible TODO placeholders remain in the underlying site and should be reviewed before production.
